# 📈 Stock Market Data Analysis

A Python-based exploratory data analysis project comparing the **risk, returns, and historical performance** of AAPL, AMZN, GOOG, and MSFT using historical time-series stock market data.

## 🎯 Objectives

- Analyze historical stock price and volume data
- Calculate daily and cumulative returns
- Compare stock volatility
- Identify the highest-returning and least-volatile stocks
- Simulate investment performance

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## 🔍 Analysis Performed

- Data cleaning and preprocessing
- Daily return calculation
- Cumulative return analysis
- Volatility analysis using standard deviation
- Historical stock performance comparison
- ₹10,00,000 investment simulation

## 📊 Key Findings

| Metric | Stock |
|---|---|
| Lowest Volatility | GOOG |
| Highest Cumulative Return | AMZN |

The analysis highlights the historical relationship between **risk and return** across the selected stocks.
